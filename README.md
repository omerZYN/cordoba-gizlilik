# cordoba-gizlilik

Privacy policy, terms of use and support pages for the Cordoba app, published with GitHub Pages.
Cordoba uygulamasının gizlilik politikası, kullanım koşulları ve destek sayfaları.

| | English | Türkçe |
|---|---|---|
| Privacy · Gizlilik | https://omerzyn.github.io/cordoba-gizlilik/ | https://omerzyn.github.io/cordoba-gizlilik/gizlilik.html |
| Terms of Use · Kullanım Koşulları | https://omerzyn.github.io/cordoba-gizlilik/terms.html | https://omerzyn.github.io/cordoba-gizlilik/kosullar.html |
| Support · Destek | https://omerzyn.github.io/cordoba-gizlilik/support.html | https://omerzyn.github.io/cordoba-gizlilik/destek.html |

Bu sayfalar uygulamanın deposundan üretilir (`npx tsx scripts/privacy-html.ts`):
`index.html` = `docs/privacy.html`; `gizlilik.html`, `terms.html`, `kosullar.html`,
`support.html`, `destek.html` aynı adlarla `docs/`'tan kopyalanır.
